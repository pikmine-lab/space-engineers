# The modpack. One Steam Workshop id per line, comments with #.
#
# This file is the source of truth. The provisioner turns it into the SE_MODS
# variable of the Dokploy service, and the container rewrites the <Mods>
# element of the world at every start. Adding a mod is `nr provision`, not a
# file edited over SSH.
#
# Order matters. When two mods change the same thing, the one further down the
# list wins, so keep frameworks and dependencies at the top and the mods that
# should have the final say at the bottom.
#
# The id is the number in the Workshop URL:
#   steamcommunity.com/sharedfiles/filedetails/?id=1902970975
#                                                  ^^^^^^^^^^
#
# Two things to know before filling this in:
#   - A fresh world is born with its mods, since the entrypoint patches the
#     seed too. The old "wait for the second start" rule no longer applies.
#   - Several mods need ExperimentalMode set to true in the dedicated config.

# --- Frameworks -------------------------------------------------------------
# They carry no content of their own and every mod below may call into them, so
# they load first. A "wrong order" here is one of the causes of the
# "Reference issue detected" failure that aborts the whole mod download.

2754014019   # Scope Framework - hand weapon scopes, code only, no definitions of its own
#
# The combat engine, and the shields that only work behind it. WeaponCore adds
# no weapon of its own: it reimplements the 18 vanilla weapon definitions in its
# own format and takes target tracking away from the turrets to run it for the
# whole grid. Defense Shields holds no reference to WeaponCore, the coupling runs
# the other way: WeaponCore is what tests a projectile against a shield, so
# without it the bullets pass straight through and the shields protect nothing.
# Hence the order, and hence the fact that neither one is worth adding alone.
#
# Three things measured before they went in, none of them stated on a Workshop
# page:
#   - Neither claims a voxel material slot, so the 66 free ones stay untouched.
#   - WeaponCore registers no damage handler, so it cannot reach damage it did
#     not cause. Vehicles breaking on terrain is a subgrid or world setting
#     matter, not this. EnableSubgridDamage is already false here.
#   - Every weapon in the encounter prefabs below is vanilla, and therefore gets
#     converted rather than dropped. The one exception is Wasteland's two
#     ARYXRailgunTurret, already absent for want of the Aryx mod.
#
# Two things to know before touching them. Turret range never exceeds
# SyncDistance, 3000 here, whatever range a weapon claims. And WeaponCore's
# server config lives in the world Storage like the MES one, so it lands a start
# late on a fresh world and belongs in overrides.txt rather than here.
3154371364   # WeaponCore - combat framework, converts vanilla weapons, drops third party ones
3154379105   # Defense Shields - needs WeaponCore above, 18 blocks, 4 of them NPC only

# --- Encounters -------------------------------------------------------------
# Content for the spawn engine, therefore after it. None of them overrides
# another, so their relative order carries no meaning here; what they do share
# is spawn slots, and that is arbitrated in the MES config, not in this file.
#
# MES filters planetary spawns on MaterialTypeName, and none of the eight
# planet mods above invents one: they all reuse the vanilla types. Terrain
# bound encounters therefore work on this system. Measured coverage:
#   Grass           -> Kerbin
#   Sand, MarsSoil  -> Kerbin, Satreus
#   Snow            -> Kerbin, Satreus, Nivis, Tohil
#   Rock, MoonSoil  -> Umbris, Torvion, Argus, Ignis, reached only by the mods
#                      that carry no terrain condition at all
#
# SWORD is the exception below: space only, so none of that applies to it. It
# is also by far the heaviest thing in this file, its battlecruiser alone at
# 25k PCU by the author's count, where MaxGlobalNpcGrids caps grid count and
# not PCU. Watch what it costs before adding more of the kind.

2621351690   # Planetary Derelicts - any planet, with or without atmosphere
2617194602   # Lost Colony + Frostbite - grass, sand and snow only

3694295503   # SWORD Faction MES - hostile navy, space only, from 300 threat level
